# assets/

**Empty by design.** `willhall020-lgtm/manual-brain` contains no logo,
no favicon, no illustrations, no photography, and no icon assets — the
product's identity is the wordmark set in Archivo 800 lowercase, and its
icons are plain unicode glyphs (see ICONOGRAPHY in the root `readme.md`).

Nothing was drawn or approximated to fill this folder. If a real logo or
brand imagery exists elsewhere, drop the files in here and they'll be wired
into the specimen cards and UI kit.
