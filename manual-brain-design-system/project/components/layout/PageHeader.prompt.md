The top of every Manual Brain screen: today's date as an eyebrow, the wordmark set in lowercase Archivo 800, and a quiet count line on the right.

```jsx
<PageHeader dateLabel="tuesday 1 september" meta="33 tasks in total · 8 done" />
```

Manual Brain has no logo mark — the wordmark IS the identity, always lowercase with -.035em tracking. Don't add a nav bar; the header is the whole chrome.
