The phone header: date eyebrow (or a back pill) over an uppercase title, with a quiet count on the right.

```jsx
<MobileNavBar dateLabel="tuesday 1 september" meta="12 tasks · 2 done" />
<MobileNavBar title="life admin" meta="5 tasks" onBack={() => go("lists")} />
```

27px instead of the web's 40px — the only concession mobile makes to the wordmark, which stays lowercase. Never use an iOS-style centred nav title; Manual Brain's title is always left-aligned.
